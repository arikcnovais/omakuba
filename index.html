omakuba

Deixa um Ubuntu LTS pronto para trabalhar com web (Node e TypeScript) e C# (.NET): terminal, editor, containers, desktop e atualizações em um comando.

  • 24.04 e 26.04 LTS
  • dotfiles com backup
  • sem telemetria
git clone https://github.com/arikcnovais/omakuba.git
cd omakuba
./install.sh
o script confere a versão e pede a senha do sudo

01. Instalar

Requisitos

Ubuntu 24.04 LTS ou 26.04 LTS com suporte a sudo.

Antes de rodar

Verifique seus dotfiles existentes em ~/.omakuba-backup.

02. O que entra

▦

Desktop

Adwaita dark com dock e Blur my Shell.

>_

Terminal

Kitty com Zsh e Starship.

JS

Web

Node LTS, pnpm, TypeScript e Prettier.
