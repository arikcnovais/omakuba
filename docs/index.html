Ubuntu 24.04 e 26.04 LTS

omakuba

Instala e configura o ambiente que eu uso no Ubuntu: Kitty, Zsh, Neovim, Node, .NET, Docker e alguns apps. O APT, os .deb e o Flatpak continuam funcionando.

Como instalar O que entra GitHub
  • 24.04 e 26.04 LTS
  • pode rodar de novo
  • dotfiles com backup
  • sem telemetria
git clone https://github.com/arikcnovais/omakuba.git
cd omakuba
./install.sh
o script confere a versão e pede a senha do sudo

Rode como o seu usuário; o script pede sudo quando precisa.

01

Instalar

Baixe o repositório, entre na pasta e rode ./install.sh. Ele confere a versão do Ubuntu antes de mexer em qualquer coisa e pede a senha do sudo no começo.

O que precisa

  • Ubuntu 24.04 LTS (GNOME 46) ou 26.04 LTS (GNOME 50)
  • uma conta com sudo
  • internet para APT, Flatpak, Homebrew, npm e downloads
  • x86_64 ou arm64; se faltar build para a sua arquitetura, o passo avisa

Antes de rodar

  • os dotfiles que já existem vão para ~/.omakuba-backup-<data>/
  • o /usr/lib/os-release original não é sobrescrito
  • não há desinstalador; os backups e o APT, Flatpak ou Homebrew são o caminho de volta

03

24.04 ou 26.04?

A base é a mesma. O que muda é o que o GNOME e os repositórios de cada versão oferecem.

Item Ubuntu 24.04 LTS Ubuntu 26.04 LTS
GNOME4650
TilingForge, com gaps e atalhos Super+h/j/k/lo tiling do GNOME; o tiling-assistant do Ubuntu fica ligado
Terminal padrãoGNOME TerminalPtyxis
.NETSDK 10 e o 8, se o repositório tiverSDK 10; o 8 não está no repositório
Search Lightextensions.gnome.orgbranch principal do GitHub, por causa do GNOME 50
Favorito do dockKittyPtyxis
Se está começando, use o 26.04. Se já está no 24.04 e usa o Forge, fique nele. Não vale reinstalar por causa do Omakuba.
04

Os 15 passos

Cada passo é um arquivo em lib/ e pode rodar sozinho: ./install.sh 20-terminal. O instalador mostra [n/15] e um resumo no fim. Se um passo falha, ele segue para o próximo.

Passo O que faz
00-baseAPT do dia a dia, Docker, lazygit e os extras do Bluefin que existem no Ubuntu
05-storeremove a Snap Store e o ubuntu-software; mantém o snapd e o comando snap
10-fontsJetBrainsMono Nerd Font em ~/.local/share/fonts
15-brandingos-release, logo, About do GNOME, Plymouth e fastfetch com a identidade do Omakuba
20-terminalKitty, Zsh, Starship, plugins e o terminal padrão do sistema
30-devnvm, Node LTS, pnpm, yarn, .NET e as ferramentas do dotnet
40-vscodeVS Code, as extensões e o merge das settings
50-gnomeextensões do Bluefin, dock, workspaces, atalhos, adw-gtk3 e claro/escuro automático
60-wallpapersregistra os wallpapers de dotfiles/backgrounds; não aplica nenhum
65-bluefin-wallpapersbaixa e registra os wallpapers do Bluefin e da Universal Blue
70-flatpaksFlathub, Bazaar, Flatseal, Mission Center e os outros apps do Bluefin
75-cliHomebrew e as ferramentas de linha de comando
80-dxcontainers, VMs e Kubernetes; só roda com OMAKUBA_DX=1
85-updateso comando omakuba e o timer semanal de Flatpak e Homebrew
90-dotfilescopia os dotfiles, com backup do que já existe
05

Comandos

omakuba update
Flatpak, Homebrew e extensões do VS Code
omakuba update --system
o mesmo, e também o APT, com sudo
omakuba doctor
versões e estado do ambiente
omakuba dock status
o dock está ligado?

O timer semanal cuida de Flatpak, Homebrew e extensões do VS Code. O APT fica com o unattended-upgrades do Ubuntu.

07

O que ele não faz

  • Não é uma distro nem uma imagem imutável. É um script que roda no Ubuntu que você já tem.
  • Não tem desinstalador. Os dotfiles antigos ficam em ~/.omakuba-backup-<data>; pacotes saem com APT, Flatpak ou Homebrew.
  • Só roda no 24.04 e no 26.04 LTS. Em outra versão ele para; OMAKUBA_FORCE=1 insiste.
  • Não substitui backup. O que o script sobrescreve é copiado, mas a cópia de segurança é sua.
08

Depois de instalar

  1. Saia e entre de novo no GNOME para as extensões e os atalhos entrarem.
  2. Rode omakuba doctor para ver o que entrou e o que ficou de fora.
  3. Os wallpapers do repositório ficam na galeria; o script não troca o seu. Para aplicar um agora: OMAKUBA_WALLPAPER=/caminho/da/imagem ./install.sh 60-wallpapers.
